# 隐私政策（ModRadar 模块雷达）

> 生效日期：以仓库首次发布日为准 ｜ 适用版本：0.1.x
> 本政策说明 ModRadar（下称「本应用」）如何处理你的数据。核心原则：**本地优先，零遥测。**

## 1 我们不收集什么

- 本应用**没有账号体系**，不要求登录，不收集手机号、邮箱、设备标识符。
- 本应用**不内置任何统计、埋点、崩溃上报、广告 SDK**，不会向开发者回传任何使用数据。
- 本应用不读取你的通讯录、短信、相册、通话记录、精确位置。

## 2 本地处理的数据

以下数据**只存在于你的设备上**：

| 数据 | 位置 | 用途 |
|---|---|---|
| 分析任务与阶段检查点 | 应用私有目录 `filesDir/tasks/` | 断点续跑 |
| 分析产物（清单摘要、结构提取结果等） | 同上 | 报告展示 |
| 大体积中间产物（解包目录等） | `cacheDir/tasks/`，可被系统清理 | 加速重算 |
| 扫描历史与会话记录 | 本机数据库 `modradar.db` | 历史列表与继续对话 |
| AI 配置（地址 / Key / 模型） | 本机 SharedPreferences | 调用你指定的 AI 服务 |

卸载本应用会一并删除以上全部数据；你也可以在应用内清空历史。

## 3 AI 能力的数据边界

**只有在你自己配置了 AI 接口、并主动发起分析或对话时**，本应用才会联网，且仅向**你填写的那个接口地址**发送：

- 结构化特征摘要（包名、权限、组件、ABI、命中特征等）
- 反编译片段与工具调用结果（用于让模型回答你的问题）

**不会上传**：APK / 模块文件本体、你的扫描历史全量数据、与本任务无关的任何文件。

- API Key 仅保存在本机，不会以任何形式回传给我们。
- 你随时可以在设置里清空配置，关闭 AI 能力；不配置 AI 时，本地静态分析完全可用。
- 你选择的 AI 服务由其提供方运营，其数据处理行为受该服务方的隐私政策约束，本应用无法控制。

## 4 权限说明

| 权限 | 用途 | 说明 |
|---|---|---|
| 通知（POST_NOTIFICATIONS） | 分析进度常驻通知 | 仅用于展示进度与暂停/继续操作 |
| 前台服务（FOREGROUND_SERVICE / _DATA_SYNC） | 切后台后继续分析 | 分析期常驻通知可见 |
| 唤醒锁（WAKE_LOCK） | 分析期间避免息屏中断 | 阶段间释放 |
| 忽略电池优化（REQUEST_IGNORE_BATTERY_OPTIMIZATIONS） | 保活引导 | **由你手动确认**，可拒绝 |
| 查询已安装应用（QUERY_ALL_PACKAGES） | 识别 Xposed 模块、跳转厂商后台设置页 | 不读取应用内的任何数据 |
| 文件访问 | 选择 APK / 模块包 | 通过系统文件选择器（SAF），逐次授权 |

**root 相关**：仅当你主动发起 KernelSU 模块实时读取时，本应用才会执行**只读**的 `su -c` 命令读取模块目录。本应用**不会**执行任何修改、安装、注入、删除系统文件的操作。

## 5 后台运行说明

为支持长时间分析，本应用会在分析期间运行前台服务并显示常驻通知（这是 Android 的强制要求，通知无法隐藏）。分析结束、暂停或取消后，前台服务即停止。本应用不申请开机自启，不做静默常驻。

## 6 数据删除

- 应用内删除任务：同时删除该任务的检查点、产物与会话记录。
- 清空历史 / 卸载应用：删除全部本地数据。

## 7 第三方组件

本应用使用了开源组件（Compose、Room、OkHttp、dexlib2、DexKit、jadx 等），这些组件在本机运行，不涉及数据外传。完整清单见仓库依赖声明。

## 8 未成年人

本应用面向具备一定技术判断能力的用户，不适用于 14 周岁以下未成年人。

## 9 政策变更

如本政策发生实质性变更，将在应用内与仓库 README 同步告知。继续使用即视为接受更新后的政策。
